# Raycast

Raycast keeps hotkeys, aliases, quicklinks, snippets and extension settings in its own encrypted database, so they can't be copied as plain files. Move them with Raycast's export instead.

1. Old Mac: Raycast → Settings → Advanced → **Export Settings & Data**. Include Settings, Extensions (with hotkeys and aliases), Quicklinks and Snippets, and **set a password**.
2. Keep the `.rayconfig` file **out of this public repo**. Snippets, quicklinks and extension preferences can contain personal data or API keys. Put it in the private `job-apps-private` repo, iCloud, or AirDrop it.
3. New Mac: Raycast → Settings → Advanced → **Import Settings & Data**, then enter the password.
